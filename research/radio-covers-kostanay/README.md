# Обложки Костаная

Исходники и воспроизводимая нормализация 14 обложек для
[`stations_kostanay.zip`](../../docs/assets/radio-packs/stations_kostanay.zip).
Список станций и частот при замене картинок не изменён.

Применены правила из [пензенского нормализатора](../radio-covers-penza/fetch_and_build.sh):
квадрат 512×512, цельный фон, сохранение пропорций и безопасные поля вокруг логотипа.
Местные обложки кодируются в WebP lossless. Встроенные пензенские обложки копируются
побайтно и не перекодируются.

## Источники

В [`manifest.csv`](manifest.csv) записаны прямые URL, имена исходников, фон и размер
композиции. Скачанные файлы сохранены без изменений в `originals/`.

| Станция | Исходник | Подготовка |
| --- | --- | --- |
| LUX FM | Официальный сайт, 1280×1280 | Прозрачный знак на белом фоне |
| Алау | [TuneIn, Radio Alau](https://tunein.com/radio/Radio-Alau-1007-s209611/), 500×500 | Чёткая версия знака вместо увеличенного favicon с сайта Алау |
| Радио КН | Официальный сайт, 843×843 | Убраны лишние белые поля; исходная тень сохранена |
| Жулдыз FM | Официальный сайт, 768×768 | Убраны поля, фон совпадает с исходником |
| Казахское радио | Официальный сайт, 351×120 | Родной размер, тёмный бирюзовый фон |
| Народное радио | CDN [официального сайта](https://narodnoeradio.kz/), 1680×704 | Новый белый логотип на сплошном фирменном зелёном фоне |
| Радио NS | Официальный сайт, 1603×692 | Крупный горизонтальный знак на белом фоне |
| Шалкар радио | Официальный сайт, 406×120 | Родной размер, тёмный бирюзовый фон |
| Жана FM | Официальный сайт, 1278×550 | Белый знак из шапки сайта на зелёном фоне |

Ни один из девяти логотипов не увеличивается сверх размера полезной области исходника
(`-resize '...>'`). Миниатюры 96 px из исходного архива не используются. Файлы Казахского
радио и «Шалкара» меньше 512 px, но размещены на квадратном фоне без увеличения.
У КН мягкая тень, а у Алау градиент являются частью исходного фирменного знака.
Логотипы не перерисовывались.

Обложки Европы Плюс, Love Radio, Ретро FM, Авторадио и Русского Радио берутся из
`media-runtime/src/main/assets/radio/covers/`: сохраняется высший приоритет Пензы,
включая станции с уточнением «Казахстан».

## Пересборка

Требуются `curl` и ImageMagick 7 (`magick`). Из корня репозитория:

```sh
# Загрузить исходники заново и собрать обложки.
research/radio-covers-kostanay/fetch_and_build.sh

# Собрать из зафиксированных исходников без сети.
ATLAS_RADIO_SKIP_DOWNLOAD=1 research/radio-covers-kostanay/fetch_and_build.sh
```

Результат: `covers/*.webp` и [`contact-sheet.jpg`](contact-sheet.jpg), в порядке частот
каталога, слева направо. Скрипт не меняет ZIP и assets приложения автоматически.
Итоговые SHA-256 исходников и обложек, а также проверка импорта ZIP записаны в
[`kostanay-2026-11-10.json`](../../docs/assets/radio-packs/kostanay-2026-11-10.json).
