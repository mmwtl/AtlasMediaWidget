# Radio covers for Penza

Исследовательский набор обложек для частот из `radio_tags_penza.txt`. Файлы не подключены к
Android-модулю и не находятся в `app/src/main/res`.

## Состав

- `covers/` — квадратные WebP 512×512 с подобранным для каждой станции фоном и
  безопасными полями вокруг логотипа;
- `originals/` — скачанные исходники без ручной перерисовки;
- `manifest.csv` — соответствие частоты, исходного тега, актуальной станции, файла и источника;
- `contact-sheet.jpg` — обзор всех 25 обложек в порядке возрастания частоты;
- `fetch_and_build.sh` — воспроизводимая загрузка и нормализация набора.

## Изменения относительно приложенного списка

- 102,8 МГц: с 6 июля 2024 года вещает Comedy Radio, не «Мост Радио».
- 107,5 МГц: с 2023 года вещает Radio Monte Carlo, не «Эхо Пензы».
- 98,0 МГц: пометка «ПЛАН» устарела — «Радио Гордость» уже вещает в Пензе.

## Ограничения

Большинство изображений взято с официальных сайтов станций. Для трех местных станций
(`Радио 101.8`, `Родное Радио`, `Радио Экспресс`) использованы копии из радиокаталогов, потому что
официальные страницы не отдают стабильный прямой файл без антибот-защиты либо не публикуют
отдельный логотип достаточного качества.

Техническая пригодность изображения не равна лицензии на распространение товарного знака.
Набор подходит для внутреннего прототипа и проверки на головном устройстве. Перед публичной
дистрибуцией приложения право использования логотипов следует согласовать с правообладателями;
наличие файла на официальном сайте само по себе такого разрешения не дает.

## Пересборка

Требуются `curl`, `ffmpeg`, `cwebp` и macOS Quick Look (`qlmanage`):

```sh
./fetch_and_build.sh
```

Для повторной композиции из уже сохранённых исходников без сети:

```sh
ATLAS_RADIO_SKIP_DOWNLOAD=1 ./fetch_and_build.sh
```
