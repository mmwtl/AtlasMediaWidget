# Atlas Media Widget

Медиакарточка-оверлей для портретных автомобильных головных устройств Geely OneOS на Android 11.
[English version](README.en.md)

Atlas Media Widget показывает на домашнем экране обложку, метаданные, прогресс воспроизведения,
кнопки управления и доступные источники звука. Состояние и команды проходят через приватный
Media Bridge protocol v1.

Приложение использует `TYPE_APPLICATION_OVERLAY`, а не системный `AppWidget`: карточка видна
только поверх HOME и не блокирует управление остальной частью экрана.

## Текущее устройство

Поддерживается только интегрированный Widget APK. В него входят:

- приложение-оверлей `:app`;
- встроенный медиарuntime `:media-runtime`;
- приватный процесс `:media` с Media Bridge, медиасессиями и диагностикой;
- адаптеры OneOS и ECarX, общие модели и тесты в `:media-core`, `:vendor-oneos` и
  `:vendor-ecarx-stub`.

Отдельный APK Atlas Media API не собирается и не нужен для работы виджета. Диагностика
медиасервиса открывается из главного экрана приложения; отдельный launcher для неё удалён из
интегрированного варианта.

## Интерфейс

Карточка занимает только выделенную ей область поверх штатного HOME. Её можно перемещать,
настраивать по размеру и внешнему виду; свободная область карточки открывает активный источник.
В настройках есть живой предпросмотр того же `MediaCardView`, который используется в overlay.

## Возможности

- Источники Bluetooth, радио, USB, Online и CarPlay/Android Auto;
- обложка, метаданные, прогресс и управление воспроизведением с учётом возможностей источника;
- локальная интерполяция прогресса без ежесекундного IPC-опроса;
- выбор размера, положения, затемнения обложки, типографики, отступов и панели управления;
- отображение только поверх HOME, перетаскивание карточки и настраиваемый порог скрытия;
- единое окно настроек из пяти секций: «Система», «Медиа», «Виджет», «Резервная копия» и
  «Диагностика»;
- выбор источника по умолчанию, задержки запуска, автовоспроизведения и поведения при потере
  источника;
- выбор Online-плеера, переключение на Online перед запуском сессии и автоматическое сворачивание
  плеера;
- радиокаталог со станциями и обложками, избранное, сетка избранных станций и навигация без
  поиска по эфиру;
- передача названия и обложки радио на приборную панель Geely OneOS DIM; для Online доступна
  отдельная опциональная передача прогресса;
- открытие активного медиаприложения или штатного экрана радио, Bluetooth и USB по нажатию на
  карточку;
- экспорт и импорт настроек в ZIP, импорт старых JSON-настроек и отдельный перенос радиокаталога
  (`stations.csv` и `covers/`);
- двухфазный импорт настроек с журналом восстановления после сбоя;
- foreground service, автозапуск после загрузки и восстановление IPC-соединения с ограниченным
  backoff;
- явные состояния подключения и недоступности вместо бессрочного показа устаревших данных;
- диагностический отчёт по медиасервису и интеграции OneOS.

## Требования и разрешения

- Android 11 или новее; `minSdk 30`, `compileSdk` и `targetSdk` — 36;
- портретный автомобильный экран, целевая конфигурация — 1440×1920;
- JDK 17 для сборки;
- разрешение «Поверх других приложений»;
- доступ к истории использования и служба специальных возможностей для определения состояния
  HOME;
- доступ к уведомлениям для чтения медиасессий Android-плееров;
- доступ к хранилищу для USB-обложек и импорта радиокаталога.

Приложение не выдаёт эти доступы самостоятельно. Автозапуск и работа в фоне также зависят от
ограничений конкретной прошивки OneOS и настроек питания.

## Установка и запуск

1. Соберите или установите единственный поддерживаемый интегрированный APK.
2. Откройте **Atlas Media Widget** и в секции **«Система»** предоставьте необходимые доступы.
3. В секции **«Медиа»** проверьте медиасервис, источник по умолчанию и параметры запуска.
4. В секции **«Виджет»** настройте размер, положение и внешний вид карточки.
5. Нажмите **«Запустить»**. При необходимости включите автозапуск после загрузки головного
   устройства.

## Сборка и проверки

Используйте Gradle Wrapper из корня репозитория:

```sh
sh gradlew --offline clean check assembleRelease
```

Для отдельной сборки приложения используется эквивалентная задача:

```sh
sh gradlew :app:assembleRelease
```

Интегрированный release APK находится в:

```text
app/build/outputs/apk/integrated/release/<effectiveVersionName>[<versionCode>]AtlasMediaWidget-release.apk
```

Базовые `appVersionName` и `appVersionCode` находятся в начале `app/build.gradle`. На ветке
`main` имя версии не получает суффикс; на остальных ветках к нему добавляется безопасное имя
ветки. Подпись зависит от локального игнорируемого `secure.signing.gradle`; неподписанный APK
не следует считать production-релизом.

## Совместимость

Основная цель — портретное головное устройство Geely OneOS на Android 11. Поведение OEM Binder,
автозапуска, медиасессий, приборной панели и управления питанием зависит от прошивки. Успешная
сборка и модульные тесты не заменяют проверку на реальном головном устройстве, особенно для
переключения источников, холодной загрузки и sleep/wake.
